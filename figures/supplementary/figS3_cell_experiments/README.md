# SI Figure S3 — GFP-tagged RhoA F-actin activity

Confocal images and quantification of GFP-RhoA / GFP-RhoA-alanine-mutant activity in
NIH3T3 cells (phalloidin F-actin normalized to GFP-RhoA expression), under wild-type and
constitutively active G14V backgrounds.

Quantification/statistics code and source CSVs are shared with main Figure 5 — see
**`../../../experiments/`** (`Analyze_experiments.py`). Panel A images are raw confocal
microscopy.
