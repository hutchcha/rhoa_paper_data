# Figure 5 — Perturbation of G-domain–lipid interaction modulates RhoA function (cell assays)

This is an **experimental** figure (NIH3T3 cells expressing HA-tagged RhoA / RhoA-3A /
RhoA-G14V / RhoA-G14V-3A; immunofluorescence for F-actin and pMLC2). It is not produced
from the MD pipeline.

- **Panel A**: representative epifluorescence micrographs (raw microscopy images).
- **Panels B–C**: per-cell F-actin (phalloidin) and pMLC2 intensities normalized to RhoA
  expression, with one-way ANOVA + Tukey post-hoc.

The quantification + statistics code and source data are in **`../../experiments/`**
(`Analyze_experiments.py` + `phalloidin_{serum,starve}.csv`, `pmlc2_{serum,starve}.csv`).
See `experiments/README.md`.
